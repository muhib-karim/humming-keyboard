# Getting help with Humming

- **Questions, bug reports and feature requests:** open an issue at
  https://github.com/muhib-karim/humming-keyboard/issues. Issues are public, so please leave out personal data.
- **Security problems and privacy requests:** report them privately through GitHub's private vulnerability reporting
  (the repository's Security tab > "Report a vulnerability", or
  https://github.com/muhib-karim/humming-keyboard/security/advisories/new). Only you and the maintainers can see it.
  See [SECURITY.md](SECURITY.md).
- **Privacy policy:** https://muhib-karim.github.io/humming-keyboard/privacy.html

Humming has no account, no analytics and no support email; GitHub is the only support channel.
