# v1.7 competitor gaps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close three competitor gaps (Bangla phonetic typing, context-aware dictation joining, more spoken punctuation)
with unit-tested pure logic.

**Architecture:** New pure-Kotlin objects next to `TextCleanup` (no Android types, JVM tests), wired into the IME at
one call site each; the spoken-punctuation rule is mirrored in the Rust (desktop) and Swift (iOS) ports.

**Tech Stack:** Kotlin + JUnit4 (`keyboard/app/src/test`), Rust `fancy_regex` + `#[cfg(test)]`, Swift + XCTest
(`ios/HummingCore`).

**Spec:** [docs/superpowers/specs/2026-10-17-v17-gaps-design.md](../specs/2026-10-17-v17-gaps-design.md)

## Global Constraints

- No local builds: tests are written first and run by CI (`keyboard.yml`, `desktop.yml`, `ios.yml`). "Run" steps below
  are CI steps; locally, only reading and a Python reference check are possible.
- No new dependencies, imports must already be used in the module.
- Existing tests must pass unchanged (anti-goal: no output change for text without the new words).
- Keep the three clean-up ports in the same rule order.

## Review Focus

1. Mixed Latin/Bangla or digits inside a word on a bn subtype → the provider must not crash; non-letters return no
   Bangla candidate. Test: `BanglaPhoneticTest.digitsAndUnknownPassThrough`.
2. Dictating at the very start of an empty field → keep capitals and the period. Test:
   `DictationJoinTest.emptyFieldKeepsSentence`.
3. A name at the start of a mid-sentence dictation ("John") → not lowercased. Test:
   `DictationJoinTest.keepsNamesAndI`.
4. "delete last word" as the whole dictation (nothing before it) → empty output, not a crash. Test:
   `TextCleanupTest.deleteLastWordAlone` (and Rust/Swift twins).
5. Words that contain the spoken tokens ("colonel", "semicolons are", "quotes") → unchanged. Test:
   `TextCleanupTest.spokenPunctuationNeedsWholeWords`.
