# Humming 1.7.1 quality pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tests, emulator smoke run, static-analysis gates, measured emulator numbers and a refreshed homepage for 1.7.1.

**Architecture:** Everything runs on GitHub Actions. Unit tests and JaCoCo in `keyboard.yml`; ktlint/detekt/gitleaks/site
checks in a new `quality.yml`; Android lint as a `keyboard.yml` job; CodeQL in `codeql.yml`; the emulator run
(smoke test, model load, cold start, screenshots) in a new `android-emulator.yml` driven by `keyboard/ci/emulator_run.sh`.

**Tech Stack:** Kotlin 2.2.20, AGP 8.12, Gradle 9.2, JUnit 4 + Robolectric 4.16, UiAutomator 2.3, ktlint 1.7.1,
detekt 1.23.8, gitleaks 8.21.2, reactivecircus/android-emulator-runner v2, CodeQL v4, Python 3 for summaries.

**Spec:** `docs/superpowers/specs/2026-10-22-v1.7.1-quality-design.md`

## Global Constraints

- Never run Gradle/cargo/Xcode locally; Kotlin is verified only by CI. Python: `pytest -x -q -p no:cacheprovider` or `unittest`.
- applicationId `com.humming.keyboard`, namespace `dev.patrickgold.florisboard`, signing: unchanged.
- Version 1.7.1 everywhere; Android versionCode 1701; CHANGELOG heading `## [1.7.1] - 2026-10-22`.
- Every README/site number comes from a committed CI output under `docs/bench/` or `docs/ci/`.
- Push only via `push.sh`; workflows must also trigger on `upgrade/**` branch pushes.

## Review Focus

- A missing baseline file: the gate must fail (each tool's script checks the file exists before running).
- Active language removed from the list: next/previous goes to the list's first language (SubtypeCycleTest).
- Model archive with a bad checksum or a `../` entry: nothing unpacked, `.verified` absent (ModelStoreTest).
- Interrupted model download (HTTP 206 resume, or server ignoring Range with 200): final file still verifies (ModelStoreTest).
- Emulator test when keys are not found: hierarchy dump + screenshot saved before the test fails (ImeSmokeTest watcher).
